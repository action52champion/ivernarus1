# Ivernarus 2

Независимое от мессенджера шифрование сообщений. Один HTML-файл, открывается оффлайн в любом современном браузере.

Вы пишете сообщение в Ivernarus 2, шифруете его, пересылаете контакту через любой канал. Неудобно, зато работает везде где есть браузер, и не зависит от того, чем ваш провайдер связи решит пользоваться завтра.

## Как открыть

Скачайте `dist/ivernarus2.html` и откройте в браузере (Chrome / Firefox / Safari / Edge). Никакой установки не нужно. Файл полностью оффлайн — в нём нет ни одного внешнего ресурса.

## Что внутри

**Шифр.** One-time pad (шифр Вернама) — единственный шифр с математически доказанной абсолютной стойкостью при правильной эксплуатации. Каждый символ сообщения смешивается со случайным символом ключа, который потом никогда не используется повторно. Без ключа расшифровать невозможно никаким объёмом вычислительных ресурсов.

**Аутентификация.** Каждое сообщение содержит 80-битный auth-тег, привязанный к ключевой позиции. Подделать или модифицировать сообщение в канале без знания ключа невозможно.

**Защита базы паролем.** Контакты, ключи и переписка на устройстве шифруются мастер-паролем (Argon2id 64МБ + AES-GCM-256). Без него локальное хранилище — несвязный набор байт.

**Режим без следов.** Опционально: данные живут только в текущей вкладке. Закрыли — на устройстве не остаётся ничего.

**Сжечь всё.** Одна кнопка (или Ctrl+Shift+Q) полностью очищает устройство — localStorage, sessionStorage, буфер обмена, in-memory state. После этого приложение выглядит будто никогда не запускалось.

## Преимущества

- Шифр Вернама — невзламываем при правильной эксплуатации.
- Зашифрованный текст использует только печатные символы и не нарушает структуру предложений (можно отсылать через любой мессенджер).
- Возможность отрицаемости переписки при включенной подрезке ключа — после расшифровки использованный кусок ключа на устройстве затирается.
- Работает везде, где можно писать по-русски или по-английски.
- Полностью оффлайн, никаких внешних запросов.

## Недостатки

- Ключ расходуется при шифровании, поэтому стандартный размер — 768 КБ (хватает на ~3900 сообщений на сторону). Можно выбрать больше при генерации.
- Нужен доверенный канал связи для передачи ключа (один раз при установке контакта). Это особенность всех one-time pad систем.

## Быстрый старт

### Установка

1. Скачайте `dist/ivernarus2.html`. Сохраните в место откуда будете всегда его открывать (рабочий стол / отдельная папка / флешка). База ключей привязана к комбинации «файл + браузер» — переезжать с базой нужно через **Экспорт/Импорт базы**.

2. Создайте контакт и привяжите к нему ключ:
    - На главной странице введите имя и нажмите «Добавить контакт».
    - На странице правки нажмите «🎲 Сгенерировать ключ».
    - Нажмите «💾 Передача ключа» — ключ скачается на устройство.
    - Нажмите «Сохранить».

3. Передайте ключевой файл контакту через **доверенный канал связи**, отличный от того через который планируете общаться. Если общаться будете в Telegram — передайте ключ через email, или WhatsApp, или при личной встрече. Только так шифрование будет безопасным.

4. Ваш контакт открывает у себя `dist/ivernarus2.html`, создаёт у себя контакт с любым именем для общения с вами, нажимает «Загрузить файл» и выбирает переданный вами ключевой файл. Сохраняет.

### Общение

1. Нажмите «Чат» напротив контакта.
2. В поле «Обычное сообщение» введите текст и нажмите «🔒 Шифровать».
3. Скопируйте полученное сообщение из поля «Шифрованное сообщение» и отправьте через любой мессенджер.
4. Полученное от контакта зашифрованное сообщение вставьте в поле «Шифрованное сообщение» и нажмите «🔓 Расшифровать».

### Настройки контакта

- **Подрезать ключ** — после каждой расшифровки использованный кусок ключа затирается случайными байтами. Старое сообщение второй раз прочитать нельзя. Защищает от forensic-анализа устройства. Работает локально и не требует синхронизации с собеседником.
- **Прятать границы слов, цифры, спецзнаки** — режим скрытия структуры. Шифрует не только буквы, но и пробелы, знаки препинания, переносы строк. Шифротекст становится неотличим от случайного шума, не выдаёт длину слов и предложений. Должен быть согласован с собеседником (передаётся в файле ключа).

### Защита устройства

В настройках:

- **Сортировка контактов** — алфавит / обратный / своя (drag-and-drop).
- **Цветовая схема** — светлая / тёмная / бумажная. Свои темы добавляются редактированием `src/themes.js`.
- **Режим без следов** — переключение между постоянным хранилищем (localStorage, переживает закрытие вкладки) и сессионным (sessionStorage, исчезает при закрытии). Полезно при работе на чужом компьютере.
- **Защита базы** — установка/смена/отключение мастер-пароля. С паролем база на устройстве лежит зашифрованной (AES-GCM 256-бит, ключ выводится из пароля через Argon2id 64МБ).
- **Автоблокировка** — после N минут простоя пароль запрашивается заново. Работает только при установленном пароле.

### Как развернуть на чужом устройстве (библиотека, интернет-кафе)

1. Откройте `ivernarus2.html` с флешки.
2. Войдите в Настройки → Режим без следов → «Включить».
3. Загрузите ваш ключевой файл, импортируйте резервную копию базы или создайте контакт.
4. Поработайте.
5. Перед уходом — Настройки → **«Сжечь всё»** (или Ctrl+Shift+Q). Всё стирается без следа.

## Безопасность

- **Шифр**: OTP с Argon2id-protected мастер-паролем + 80-бит auth-тег.
- **Гамма**: 4 байта ключа на каждый шифруемый символ через rejection sampling — равномерное распределение, без модульного биаса.
- **CSP**: hash-based `script-src`, без `'unsafe-inline'`. Любой инжект скрипта через XSS не выполнится — браузер сверит SHA-256.
- **Никаких внешних ресурсов**: ни шрифтов, ни аналитики, ни fetch. CSP `connect-src 'none'`. Открывается полностью оффлайн.
- **Защита от prototype pollution**: парсинг user-controlled JSON через reviver, отбрасывающий `__proto__`/`constructor`/`prototype`.
- **Replay-защита**: журнал расшифрованных позиций ключа на контакт, отвергает повторы.
- **Прогрессивная задержка** после неудачных вводов мастер-пароля.

### Что это **не** защищает

- **Memory dump** работающего процесса — расшифрованные ключи и пароль в моменте лежат в памяти JS. Аппаратные хранилища ключей (TPM/Secure Enclave) браузеру недоступны.
- **Malicious browser extension** — расширения видят DOM и localStorage, перехватывают clipboard. Используйте чистый профиль.
- **Скриншот / screen-share / shoulder-surfing** — текст на экране всегда виден тому, кто на него смотрит.
- **Подмену самого html-файла** — chicken-and-egg, нужна внешняя проверка хеша. Скачивайте только из доверенных источников.
- **Компрометированную ОС** — keylogger / rootkit обходят браузерную песочницу.

## Сборка из исходников

```bash
npm install                # один раз
npm run build_html         # собирает dist/ivernarus2.html
npm run tests              # запускает тесты шифра
```

Чтобы пересобрать `src/argon2id.js` из `@noble/hashes` (нужно только если меняются параметры/версия):

```bash
npm run bundle_argon2
```

## Структура

```text
src/
  IVernarus2.js     - класс шифра (OTP + auth-тег + кодировка)
  template.html     - UI-шаблон, в нём data-action делегаты, lock-modal, темы
  themes.js         - цветовые палитры, добавляются новыми блоками
  argon2id.js       - бандл @noble/hashes argon2id (генерируется bundle_argon2)
scripts/
  builder.js        - собирает dist/ivernarus2.html из шаблона
  bundle_argon2.js  - один раз генерирует argon2id.js
tests/
  test_suite.js     - тесты шифра (Node:test)
  testKey.txt       - 1KB случайных печатных символов для тестов
dist/
  ivernarus2.html   - собранный файл (распространяется пользователям)
```
